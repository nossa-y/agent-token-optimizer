# Code Of Conduct

This project should be a practical, respectful place to collaborate.

## Expected Behavior

- Be direct, specific, and constructive.
- Assume good intent while still asking for evidence.
- Keep technical disagreement focused on facts, tradeoffs, and user impact.
- Respect privacy. Do not post secrets, private source code, private cache files, or
  private host configuration.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Discriminatory language or conduct.
- Publishing private information without explicit permission.
- Repeatedly derailing issues or pull requests after maintainers have redirected the
  discussion.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; block users; or limit
participation when behavior harms the project or its users. Enforcement should be
proportionate, documented when practical, and focused on keeping the project useful and
safe.
